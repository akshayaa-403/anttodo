How the algorithm works

Each ant builds one complete ordering, choosing the next task with probability

P(i→j) = τ(i,j)^α · η(i,j)^β / Σ τ(i,l)^α · η(i,l)^β

τ is pheromone deposited by previous ants; η is the heuristic (1/cost of stepping from i to j). After every iteration all trails evaporate by ρ, then the best-so-far ordering deposits 1/cost on its edges. Good edges compound; bad ones fade.

This is a Max-Min Ant System: pheromone is clamped to [τmin, τmax] so no single trail can dominate and stall the search — the classic failure mode of naive ACO. Each ant's ordering is then polished with dependency-aware 2-opt segment reversal.

Errand Mode is a literal Traveling Salesman Problem: tasks are places, η = 1/km using haversine distance, and the tour returns home. Focus Mode applies the same colony to task sequencing, where cost is a weighted sum of deadline misses, priority inversion, context switching and cognitive-load timing. Dependencies apply to Focus Mode only — a closed TSP tour has no start, so "before" is undefined there.
